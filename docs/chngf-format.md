# Формат файла ХроноГраф 3.0 Мастер (`*.chngf`)

Восстановлен по двум образцам (версии `M3.210306.004f` 2006 г. и
`M3.291012.004n` 2025 г.) и по описанию COM-интерфейса из дистрибутива программы (`Document/Spec`).
Реализация — `timetable_upload/chngf.py`.

## Примитивы

| тип   | кодирование |
|-------|-------------|
| `i32`, `i16`, `u8` | little-endian |
| `f64` | double; даты — TDateTime Delphi (дни от 30.12.1899), время дня — доля суток |
| `str` | `i32 1000` (маркер) · `i32 длина` · байты cp1251 |
| объект | начинается с пары `i32 typeId, i32 version` |

Списки — `i32 count` и затем элементы. Маркеры `2000`/`2001` — список
параллелей и его элементы.

## Контейнер

```
str "arc header"; i32×4; u8; i32
str заголовок; str комментарий; str имя проекта; f64 дата сохранения
i32×5; str версия; str ''
i32 nfiles; nfiles × (str имя, i32 размер, байты)      — NewTimeTable.dat, info.txt, Info.dat
```

## NewTimeTable.dat

```
i32 -1; i32 0; i32 38; str версия
i32×8: ?, ?, ?, ?, ?, DayCount, LessonCount, WeekCount
KeyBase ×3: (14,1) идентичные группы; (14,1) потоки; (14,1) пустая
str учебный год; str название полугодия; f64 начало; f64 конец
i32 1; i32 1; u8 1; i32 1
i32 n; n×f64 начало уроков; i32 n; n×f64 конец уроков
i32 0; u8 0
i32 n; n × Cabinet
i32 n; n × Teacher
i32 n; n × ClsGrp
i32 n; n × Cls
i32 2000; i32 n; n × (i32 2001; i32 номер; str имя; str префикс; i32 k; k×i32 индексы классов)
i32 n; n × Subject
i32 n; n × ClsGrpLessons            — столько же, сколько ClsGrp, в том же порядке
i32 n; n × Lang
i32 n; n × ((19,1); i32 0; str)     — справочник базовых предметов
(2010,1); str город; str код региона; i32; str название школы; …
```

Сетка любого объекта — плоский массив длиной `DayCount·LessonCount·WeekCount`,
индекс `(week·DayCount + day)·LessonCount + lesson`. Перед сеткой всегда пять
`i32`: `?, ?, LessonCount, DayCount, WeekCount` (первые два в образцах 9 и 2).

### KeyBase (14, 1)
```
i32 n; n × (i32 key, i32 groupIdx, i32 identIdx)
i32 g; g × (i32 c; c × (i32 key, i32 idx))     — группы ключей
i32 g; g × (i32 c; c × (i32 key, i32 idx))     — группы идентичных ключей
```
Ключи — `ClsGrp.key`. Первая база: группы = классогруппы одного класса по
одному предмету, идентичные = совпадающие по составу. Вторая: группы = потоки
(классогруппы, занимающиеся вместе).

### Cabinet (3, 3)
`dims; str имя; i32 вместимость; i32 этаж; сетка × ((4,1); u8 busy); i32 tag`

Один кабинет может быть занят несколькими преподавателями одновременно (программа это допускает).

### Teacher (5, 11)
```
u8; i32 «Общее количество рабочих дней преподавателя в неделю» — верхняя граница, справка программы 09-07, 10-03 (-1 — не задано); dims
str фамилия (или «Фамилия И.О.» целиком); str имя; str отчество
i32 a; i32 b (a = 1 — b = индекс закреплённого кабинета; иначе 0, 11); i32 k; k×i32; i32; u8×3
сетка × ((2,2); i16 busy; i32 индекс кабинета или -1; u8 занятие с кабинетом)
str код; i32 -1; i32 0; i32 0
```

### ClsGrp (1, 3)
`i32 0; dims; i32 group (0 — весь класс); i32 численность; i32 нагрузка; i32 key; u8 pairs`

Связи с предметом/классом/учителем хранятся в Subject.

### Cls (6, 11)
```
i32 n; n × Student                  — только в «колледж»-классах, иначе 0
i32 закреплённый кабинет (-1 — нет); dims; i32 0; i32 -1; i32 смена; i32 0; u8; i32 мальчиков; i32 девочек
str имя; str полное имя; i32 (-1)
сетка × ((7,1); i16 busy)
i32 -1; i32 0; i32 0
```
Student (14, 9): `i32 номер; i32 0; str×3; i32; str фамилия; str имя; str отчество; u8; i32 пол(1 м/2 ж); i32×7; str×4; i32×2; str`.

### Subject (10, 5)
```
i32 id; str имя; str сокращение; i32; i32; i16
i32 n; n × (i32 индекс учителя; (12,1); i32 k; k×i32 индексы ClsGrp)   — SubjTeacher
i32 n; n × (i32 индекс класса; (11,2); u8; i32 нагрузка; i32 k; k×i32 индексы ClsGrp) — SubjCls
i32 n; n×i32 индексы кабинетов
```

### ClsGrpLessons (8, 2)
`i32 DayCount; i32 LessonCount; i32 WeekCount; сетка × u8 (1 — занятие есть)`

### Lang (13, 2)
`str имя; str сокращение; i32 n; n×i32 индексы учителей; i32 n; n×i32 индексы ClsGrp; i32 tag`

## Как собирается расписание

Занятие = классогруппа × слот, где `ClsGrpLessons[slot] = 1`. Класс и предмет —
из `SubjCls`, учитель — из `SubjTeacher`, кабинет — из сетки учителя на том же
слоте (`cabinet >= 0`). Если классогруппа входит в `Lang.clsgrps`, предмет в
расписании — название языка. Потоки — группы второй KeyBase.
